================================================================================
     PERBEDAAN DETAIL HAK AKSES PENGGUNA (ROLE-BASED ACCESS CONTROL)
               SISTEM INFORMASI PERSEDIAAN DELLA FROZEN MART
================================================================================

Sistem Della Frozen Mart menggunakan arsitektur keamanan Role-Based Access Control
(RBAC). Keamanan ini diterapkan ganda: secara visual pada tampilan menu (Sidebar)
serta secara backend di tingkat server (Route Middleware) untuk mencegah
akses ilegal (URL Hijacking).

Berikut adalah penjelasan detail pembagian hak akses, fungsi, dan wewenang
dari masing-masing 3 aktor utama (Admin, Manager, dan Owner):

--------------------------------------------------------------------------------
1. AKUN ADMIN (Staff Gudang / Operasional Master Data)
--------------------------------------------------------------------------------
Admin bertanggung jawab penuh atas pencatatan fisik barang di lapangan dan 
keabsahan data produk/supplier di database.

Wewenang & Hak Akses (BISA DIAKSES):
* Kelola Master Data:
  - Membuat, melihat, mengupdate, dan menghapus data Produk (CRUD).
  - Membuat, melihat, mengupdate, dan menghapus data Supplier (CRUD).
* Transaksi Gudang:
  - Mencatat data Barang Masuk.
  - Mencatat data Barang Keluar (rusak, expired, penjualan, penyesuaian).
  - Mencatat data penyesuaian Stok Opname fisik.
* Analisis & Peringatan:
  - Melihat riwayat kalkulasi Analisis Persediaan (Safety Stock & ROP).
  - Memicu kalkulasi ulang Safety Stock & ROP per produk secara manual.
  - Menerima Notifikasi Peringatan Stok Kritis (Warning/Order/Expired).
* Laporan & Ekspor:
  - Mengakses Laporan Barang Masuk (dan ekspor Excel/PDF).
  - Mengakses Laporan Barang Keluar FIFO COGS (dan ekspor Excel/PDF).
  - Mengakses Laporan Penjualan Produk (tanpa data keuangan/finansial, dan ekspor Excel/PDF).

Batasan Keamanan (TIDAK BISA DIAKSES):
* Tidak memiliki menu "Import Penjualan" spreadsheet.
* Tidak memiliki menu "Status Stok" (Visual Pie Chart Owner).
* Tidak dapat melihat angka finansial sensitif di dashboard (Omzet & Laba) maupun pada Laporan Penjualan Produk (Harga Jual, Total Omzet, Laba Kotor, dan Margin Profit disembunyikan secara dinamis pada web, cetak PDF, dan ekspor Excel).

--------------------------------------------------------------------------------
2. AKUN MANAGER (Supervisor / Analis Perencanaan Persediaan)
--------------------------------------------------------------------------------
Manager bertugas menganalisis pergerakan persediaan, mengunggah data omzet,
serta mengontrol parameter perhitungan safety stock.

Wewenang & Hak Akses (BISA DIAKSES):
* Unggah Data Penjualan (Khusus):
  - Mengunggah file spreadsheet excel penjualan harian/bulanan (Import Penjualan).
* Transaksi Gudang:
  - Mencatat data Barang Masuk.
  - Mencatat data Barang Keluar.
  - Mencatat penyesuaian Stok Opname.
* Analisis & Perencanaan:
  - Melihat & memicu kalkulasi parameter Safety Stock dan ROP (Reorder Point).
  - Menerima Notifikasi Peringatan Stok Kritis.
* Laporan & Ekspor:
  - Mengakses Laporan Barang Masuk (dan ekspor Excel/PDF).
  - Mengakses Laporan Penjualan Produk (tanpa data keuangan/finansial, dan ekspor Excel/PDF).

Batasan Keamanan (TIDAK BISA DIAKSES):
* Diblokir dari menu Master Data (Kelola Produk/Supplier) untuk mencegah 
  manipulasi data dasar produk.
* Diblokir dari Laporan Barang Keluar (FIFO) beserta ekspor Excel/PDF-nya.
* Diblokir dari menu "Status Stok" (Visual Pie Chart Owner).
* Tidak dapat melihat angka finansial sensitif di dashboard (Omzet & Laba) maupun pada Laporan Penjualan Produk (Harga Jual, Total Omzet, Laba Kotor, dan Margin Profit disembunyikan secara dinamis pada web, cetak PDF, dan ekspor Excel).

--------------------------------------------------------------------------------
3. AKUN OWNER (Pemilik Toko / Manajemen Finansial)
--------------------------------------------------------------------------------
Owner memantau kesehatan bisnis, arus keuangan toko, dan mengambil kebijakan
pembelian barang strategis.

Wewenang & Hak Akses (BISA DIAKSES):
* Dashboard Keuangan (Penuh & Khusus):
  - Melihat total omzet rupiah, laba kotor, dan persentase margin keuntungan.
  - Melihat grafik interaktif tren omzet penjualan per bulan.
  - Melihat daftar Produk Terlaris (Top Selling Products).
* Visualisasi Status Stok (Khusus):
  - Mengakses menu Status Stok berupa Pie Chart (Aman vs Warning vs Order).
* Pemantauan Pemesanan:
  - Melihat riwayat Purchase Order (Pemesanan Supplier).
* Laporan & Ekspor:
  - Mengakses Laporan Barang Masuk (dan ekspor Excel/PDF).
  - Mengakses Laporan Barang Keluar (dan ekspor Excel/PDF).
  - Mengakses Laporan Penjualan Lengkap (termasuk seluruh metrik keuangan, cetak PDF, dan ekspor Excel).
* Peringatan:
  - Menerima Notifikasi Peringatan Stok Kritis.

Batasan Keamanan (TIDAK BISA DIAKSES):
* Diblokir dari pengisian transaksi operasional (tidak bisa input barang masuk/
  keluar, stok opname, atau upload excel). Hal ini menjaga prinsip "Separation
  of Duties" (Pemisahan Tugas) sehingga Owner murni menerima laporan hasil kerja.
* Diblokir dari pengelolaan CRUD master data produk/supplier.
* Diblokir dari menu Analisis Persediaan utama (Safety Stock/ROP detail).

--------------------------------------------------------------------------------
MATRIKS RINGKASAN ROUTE SECURITY (web.php)
--------------------------------------------------------------------------------
* `/produk`, `/supplier`, `/pengguna`    -> Hanya role:admin
* `/import-penjualan`                   -> Hanya role:manager
* `/status-stok`                         -> Hanya role:owner
* `/laporan/barang-keluar`               -> Hanya role:admin,owner
* `/barang-masuk`, `/stok-opname`        -> Hanya role:admin,manager
* `/laporan/penjualan`, `/notifikasi`    -> Terbuka untuk: admin,manager,owner

--------------------------------------------------------------------------------
CATATAN TAMBAHAN: KEAMANAN DINAMIS LAPORAN PENJUALAN (DYNAMIC RBAC SECURITY)
--------------------------------------------------------------------------------
Untuk menyeimbangkan kebutuhan operasional dan keamanan finansial perusahaan:
1. Akses Menu & Penamaan Dinamis:
   * Menu Sidebar disesuaikan secara dinamis berdasarkan Peran/Role:
     - Admin & Manager melihat menu sebagai "Laporan Penjualan Produk" (fokus stok/volume).
     - Owner melihat menu sebagai "Laporan Penjualan" (laporan finansial lengkap).
2. Pembatasan Kolom Keuangan (Dynamic Column Filtering):
   * Admin dan Manager diperbolehkan mengakses halaman laporan penjualan demi melihat 
     volume produk terjual (stok keluar untuk penjualan) agar sinkron dengan operasional gudang.
   * Namun, kolom finansial sensitif berikut DISEMBUNYIKAN SECARA OTOMATIS:
     - Harga Jual
     - Total Omzet (Pendapatan)
     - Laba Kotor
     - Margin Profit (%)
   * Baris ringkasan keuangan (Summary Cards) di bagian atas halaman juga disembunyikan.
3. Keamanan Tingkat Backend (Web View, PDF, dan Excel):
   * Proteksi ini tidak hanya berlaku pada visual HTML (CSS/Blade), melainkan diimplementasikan
     di sisi server (Controller/Backend).
   * File PDF Cetak dan file Excel Ekspor (.xlsx) yang diunduh oleh Admin/Manager secara
     otomatis tidak akan memuat kolom finansial tersebut. Kolom tersebut hanya akan di-render 
     jika yang mengunduh adalah Owner.
