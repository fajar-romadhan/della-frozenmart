CATATAN PENGGUNAAN RESET DEMO (reset_demo.php):
--------------------------------------------------------------------------------
1. Untuk bimbingan dosen, buka URL Demo Reset di atas.
2. Klik tombol "Kosongkan Database".
3. Semua data produk dan transaksi akan dikosongkan secara instan.
4. Anda dapat login menggunakan akun Admin, Manager, atau Owner default
   (lihat berkas infoakun.txt untuk data email & password default).
5. Setelah bimbingan selesai, Anda dapat memulihkan kembali seluruh data 
   simulasi contoh dengan mengklik "Isi Data Contoh" di halaman reset tersebut.
